# Clash-Rule
clash规则

## 订阅转换远程配置

`subconverter.ini`：订阅转换的远程配置。分组：国外流量、港/日/台节点、AI网站（不含香港节点）、E站看图、国内流媒体、游戏平台直连、国内直连、其他流量。分流规则来自本仓库和 [blackmatrix7/ios_rule_script](https://github.com/blackmatrix7/ios_rule_script)。

在订阅转换工具的「远程配置」里填：

```
https://raw.githubusercontent.com/tiger-git2022/Clash-Rule/main/subconverter.ini
```

转换链接请用 `expand=false`（不展开规则）：配置里只引用规则文件，由客户端自行下载并每天更新，配置文件约 30KB。
